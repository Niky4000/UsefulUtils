Скачивание и компиляция:
git clone https://github.com/Niky4000/bergstar.git
mvn clean install

Пример запуска для Linux:
java -jar target/bergstart.jar -path /tmp/some2.json -url https://raw.githubusercontent.com/bergstar/testcase/refs/heads/master/okved.json -phone +7926-881-41-41

Пример результата:
7926-881-41-41
Normalized phone number: +79268814141
Item code: 14.14.1
Item name: Производство трикотажного и вязаного нательного белья
Coincidence length: 5

Пояснения:
Лишних зависимостей использовано не было. Это консольная утилита.
Было использовано дерево поиска. Сложность алгоритма O(log(n)). В начале происходит инициализация входными данными справочника ОКВЭД. Для осуществления поиска входная строка разбивается по символам и в цикле идёт по рекурсивной структуре до тех пор пока находятся ненулевые узлы, это и будет код ОКВЭД, найденный по максимальному совпадению кода.

В нашем примере телефон заканчивается на 14141. В результате находится соответствующая запись 14.14.1 в справочнике. Точки игнорируются.
Поиск начинается с символа 1, далее находится узел 4, потом внутри него 1, 4 и снова 1. Дальнейший поиск не найдёт никакого узла, поэтому 14141 будет максимальным совпадением.


В данном случае для удобстава была использована одна зависимость:
        <dependency>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
            <version>2.4.4</version>
        </dependency>
